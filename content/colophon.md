This site uses [Zola](https://www.getzola.org), Markdown, and the Archivo typeface. GitHub Pages hosts it; pull requests have their own preview URLs.

[KaTeX](https://katex.org) renders equations. [GoatCounter](https://www.goatcounter.com) provides visit statistics. The layout uses plain HTML, CSS, and a small amount of JavaScript.

The [CV](@/cv/_index.md), [text profile](/cv/profile.txt), [JSON profile](/cv/public-profile.json), [PDF](/cv/jien-weng-lai-public-cv.pdf), and [llms.txt](/llms.txt) share the same public source data. Builds regenerate the exports and check them for consistency. The text and JSON profiles also include the [Now page](@/now.md).

For recent changes, see the [site log](@/log.md).
