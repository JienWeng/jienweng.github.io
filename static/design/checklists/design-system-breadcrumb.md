# Breadcrumb — Design system

A breadcrumb is a secondary navigation element that shows users their current location within a specific hierarchy of a website or app.

Source: https://www.checklist.design/design-system/breadcrumb

## Items

### Current location
The current page shown as the final item in the trail, visually distinct from the preceding levels, typically not a link

### Level links
All preceding levels rendered as active links, each one navigating directly to that level rather than requiring back-button presses

### Separator character
A consistent visual separator between levels (a slash, chevron, or arrow) distinguishing hierarchy from a list of links

### Truncation for long paths
Deep hierarchies collapsed with an ellipsis, preserving the root and current page while hiding intermediate levels behind a toggle

_Tip: Breadcrumbs that wrap onto multiple lines disrupt page layouts significantly more than a collapsible ellipsis. Truncation at three to four visible levels is a consistent point of balance_
