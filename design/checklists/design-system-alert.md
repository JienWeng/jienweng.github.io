# Alert — Design system

Source: https://www.checklist.design/design-system/alert

## Items

### Descriptive message
Alert copy that explains what happened and what the user needs to do, rather than generic labels like 'Error' or 'Success'

### Placement and stacking
Where alerts appear in the layout, inline near relevant content, at the top of a form, or in a fixed notification area, and how multiple simultaneous alerts are ordered

### Dismissible option
A close button on alerts that are informational and don't require action, letting the user clear them when they're done

### Icon reinforcement
An icon alongside the message that reinforces the alert type, not as a substitute for colour but as a signal for colour-blind users

### Semantic variants
Distinct visual treatments for informational, success, warning, and error states, using colour, iconography, or both

### Inline action (if applicable)
An optional link or button inside the alert for the most relevant next action, avoiding the need to navigate elsewhere to resolve it
