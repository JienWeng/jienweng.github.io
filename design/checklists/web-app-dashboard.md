# Dashboard — Web app

The first screen a user sees after logging in, providing an at-a-glance overview of the most relevant data, actions, and recent activity.

Source: https://www.checklist.design/web-app/dashboard

## Items

### Welcome state
A brief summary of what's happened since the last visit immediately re-orients returning users

_Tip: A personalised greeting can be a nice touch but isn't ultimately necessary_

### Key metrics
The numbers most relevant to the user's goals, readable without leaving the home screen

_Tip: Time period context (daily, weekly, monthly) gives numbers meaning at a glance_

### Recent activity
The most recently created or updated items, enabling users to resume work without hunting

### Needs attention
Time-sensitive items requiring a decision, surfaced here instead of buried in another view

_Tip: Alert fatigue can happen if this is overdone, so ensure what needs attention is critical and relevant_

### Quick actions
Shortcuts to the most common tasks, accessible without navigating away.

_Tip: The action users take most frequently after landing is what belongs here_

### Empty state
The state shown when there is nothing to show yet, with a clear first action

_Tip: A blank dashboard is one of the most common reasons new users churn_

### Layout control (if applicable)
Controls to show, hide, or reorder widgets so the home screen matches how the user works
